## Summary
Writes down the rules that keep the shared contract safe, and updates internal docs that still point at the old locations.
- **The rules:** a wire field added after the first `hassette-wire` release must be optional with a default. Adding an enum member or Literal value is a version-skew change in the older-client/newer-server direction, which #2386's lenient parsing handles. A deliberate wire break is recorded in `tools/wire_compat_ignore.txt`.
- **Where the rules go:** the `hassette_wire` package docstring, `wire/README.md`, and `CONTRIBUTING.md`.
- **Old locations:** internal docs (REVIEW.md files, `.claude/rules`) still point at `web/models.py`. This task updates them.
- **Final gate:** runs the full local suite, lint, and type check over the finished change.
