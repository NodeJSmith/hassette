   the design, this does not trigger a FAIL under the stated rubric — but it is a real gap between

   sets") and what the `depends_on` graph actually enforces. Recommend either widening T06's
   `depends_on` to include T02, T03, and T05, or documenting explicitly (in context.md or a task
   field) that PR grouping is a manual/orchestration-level concern independent of `depends_on`.
